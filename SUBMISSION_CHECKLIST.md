# Before submitting

- [ ] Run `python main.py` and check the menu opens.
- [ ] Test the joke API option while connected to the internet.
- [ ] Test prompt generation.
- [ ] Test file organization using `sample_files/` or a copy of a test folder.
- [ ] Add your name/student details if your instructor requires them.
- [ ] Create a public GitHub repository and upload these project files.
- [ ] Open the repository URL in a private/incognito window to confirm it is public.
- [ ] Paste the repository URL into the assignment submission box.
